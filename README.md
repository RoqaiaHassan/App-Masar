## الفكرة

كثيرًا ما تبقى الأهداف الكبيرة عامة ويصعب البدء بها. يساعدك «مسار» على تقسيم كل هدف إلى خطوات صغيرة، وربطها بمجال ومدة زمنية، ثم متابعة إنجازها واحدة تلو الأخرى. يتحدث التقدم تلقائيًا مع إكمال الخطوات، وتنتقل الأهداف المكتملة إلى قائمة مستقلة.

<a id="features"></a>
## المزايا

- إنشاء حساب محلي باسم وكلمة مرور، وتسجيل الدخول في مرات الاستخدام التالية.
- إضافة الأهداف وتعديلها وحذفها، مع تحديد اسم الهدف وتصنيفه وتاريخ بدايته ونهايته.
- تقسيم الهدف إلى خطوة فرعية واحدة أو أكثر، ووضع علامة إنجاز لكل خطوة.
- عرض نسبة التقدم، وعدد الخطوات المنجزة والمتبقية، والأيام المتبقية أو حالة التأخر.
- فصل الأهداف الجارية عن المكتملة، مع تصفية القوائم حسب التصنيف.
- عرض ملخص عام للأهداف والإنجازات، وتعديل الاسم من الإعدادات.
- اختيار المظهر الفاتح أو الداكن، ومسح جميع الأهداف عند الحاجة.
- واجهة عربية واتجاه كتابة من اليمين إلى اليسار.

### تصنيفات الأهداف

العمل، الدراسة، الرياضة، الصحة، المال، الشخصي، والعام.

<a id="usage"></a>
## طريقة الاستخدام

1. عند أول تشغيل، أنشئ حسابًا محليًا بإدخال الاسم وكلمة المرور وتأكيدها. في المرات التالية سجّل الدخول بالحساب نفسه.
2. من الصفحة الرئيسية اختر **إضافة هدف**، ثم أدخل عنوان الهدف واختر تصنيفه والفترة الزمنية.
3. أضف الخطوات التي ستوصلك إلى الهدف، ثم احفظ الخطة. يجب إدخال هدف وخطوة واحدة على الأقل.
4. افتح الهدف من القائمة، واضغط على كل خطوة لتبديل حالتها بين منجزة وغير منجزة.
5. راقب نسبة الإنجاز والوقت المتبقي، وعدّل الهدف أو صفِّ القائمة من الصفحة الرئيسية عند الحاجة.

يُعد الهدف مكتملًا عندما تكون لديه خطوة فرعية واحدة على الأقل وتُنجز جميع خطواته. لذلك، لا يُعدّ مرور تاريخ النهاية وحده الهدف مكتملًا.

<a id="how-it-works"></a>
## كيف يعمل التطبيق؟

- يبدأ التطبيق بتحميل الحساب والإعدادات والأهداف من قاعدة بيانات SQLite المحلية، ثم يقرر عرض الصفحة الرئيسية أو شاشة تسجيل الدخول.
- تحفظ طبقة الحالة (`AppState`) التغييرات وتُحدّث الواجهة عند إضافة هدف أو تعديله أو تغيير حالة خطوة.
- تخزن `DatabaseService` الأهداف وخطواتها وإعدادات الحساب في قاعدة `masar.db` على الجهاز. تبقى البيانات بعد إغلاق التطبيق.
- يُحسب تقدم الهدف من نسبة الخطوات المنجزة إلى إجمالي الخطوات. وتُستخدم هذه الحالة للفصل بين الأهداف الجارية والمكتملة.

<a id="privacy"></a>
## الخصوصية ونطاق البيانات

هذا الإصدار يعمل محليًا على الجهاز ولا يستخدم خادمًا أو حسابًا سحابيًا؛ لذلك لا توجد مزامنة بين الأجهزة أو استعادة للحساب عبر الإنترنت. كلمة المرور لا تُخزن كنص ظاهر، بل تُحوّل إلى بصمة SHA-256 محلية. هذا مناسب لحساب محلي بسيط، لكنه ليس بديلًا عن نظام مصادقة آمن لخدمة متصلة بالإنترنت.

خيار **التذكيرات اليومية** ظاهر في الإعدادات وتُحفظ قيمته، لكن جدولة الإشعارات وإرسالها غير مفعّلين في التنفيذ الحالي.

## المتطلبات

- Flutter SDK متوافق مع Dart 3 أو أحدث ضمن سلسلة Dart 3 (`>=3.0.0 <4.0.0`).
- Android Studio أو أدوات Android لتشغيل وبناء نسخة Android.
- لتشغيل نسخة iOS أو بنائها، يلزم macOS وXcode.

المشروع يتضمن مجلدات لمنصات Flutter الأخرى أيضًا، لكن دعمها غير مضمون في هذا الإصدار؛ تخزين SQLite المستخدم هنا يعتمد على إضافات المنصة.

## التشغيل محليًا

نفّذ الأوامر من مجلد المشروع الذي يحتوي على `pubspec.yaml`:

```bash

flutter pub get
flutter run
```

